# Gabriel Mihali | Digital Infrastructure Architect

> A modern, highly optimized portfolio built with Next.js App Router, deployed at the Edge via Cloudflare Pages.

**Live Portfolio:** [gabrielmihali.com](https://gabrielmihali.com)

## Tech Stack & Architecture
* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Hosting & CI/CD:** Cloudflare Pages (Global Edge Network)
* **Backend/Mailing:** Resend API

## AI-Augmented Development Workflow
*This project was developed using an advanced AI-augmented workflow. It demonstrates my ability to leverage Large Language Models and Generative AI as pair-programming partners and architectural sounding boards:*

* **Architectural Problem Solving:** Collaborated with AI to troubleshoot complex Next.js Edge Runtime limitations on Cloudflare, successfully transitioning from dynamic route errors to a stable, static-asset deployment structure.
* **Infrastructure Management:** Used AI-assisted logic to configure custom `_headers` and `_redirects` files, effectively preventing SEO cannibalization between the production domain and the staging `.pages.dev` environment.
* **Asset & Brand Generation:** Iterated with AI image models to ideate and conceptualize the geometric "G" logo, which was then optimized and integrated as the core site favicon without relying on external graphic design teams.
* **Responsive Fluid Design:** Paired with AI to engineer highly specific Tailwind CSS breakpoints (e.g., handling typography on ultra-narrow 320px screens), ensuring a pixel-perfect, overflow-free UI across all devices.

## Performance & Optimization
* Strict implementation of semantic HTML5 and accessibility standards.
* Global Edge deployment for zero cold-starts and sub-second load times.
* Granular control over the `metadata` API in Next.js to ensure perfect social sharing cards and native iOS icons.
